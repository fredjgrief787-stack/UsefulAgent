# Useful

AI-агент с поддержкой использования инструментов (tool use) на базе Claude API.

## Возможности

Агент может:
- 📖 **Читать файлы** - анализировать содержимое любых файлов в проекте
- 🌳 **Показывать структуру директорий** - отображать дерево файлов и папок
- 💬 **Общаться на естественном языке** - отвечать на вопросы и помогать с задачами
- 🔧 **Самостоятельно вызывать инструменты** - Claude решает, когда использовать инструменты

## Установка

```bash
# Установка зависимостей
pnpm install

# Настройка API ключа
# Создайте файл .env и добавьте:
# ANTHROPIC_API_KEY=your_api_key_here
```

## Использование

### Запуск агента

```bash
# Сборка проекта
pnpm build

# Запуск агента
pnpm start

# Или одной командой
pnpm dev
```

### Примеры запросов

```
> Прочитай src/index.ts и объясни, как он работает

> Покажи структуру проекта

> Какие файлы есть в папке src/tools?

> Прочитай package.json и скажи, какие зависимости используются
```

### Старые команды (для обратной совместимости)

Агент также поддерживает прямые команды:
- `/tree` - показать дерево директорий
- `/read <путь>` - прочитать файл
- `exit` - выход

## Архитектура

```
src/
├── index.ts              # Главный файл с циклом агента
├── prompt.ts             # Системный промпт для Claude
└── tools/
    ├── definitions.ts    # Определения инструментов для API
    ├── executor.ts       # Выполнение инструментов
    ├── readFile.ts       # Чтение файлов
    └── tree.ts          # Построение дерева директорий
```

## Как это работает

1. **Пользователь** отправляет запрос
2. **Claude** получает запрос вместе с определениями доступных инструментов
3. **Claude решает**, нужны ли инструменты для ответа
4. Если нужны - **вызывает инструменты** (может несколько за раз)
5. **Агент выполняет** запрошенные инструменты
6. **Результаты отправляются** обратно Claude
7. **Claude анализирует** результаты и даёт финальный ответ
