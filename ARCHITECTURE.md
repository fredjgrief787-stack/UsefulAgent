# Новые архитектурные директории

## `src/core/`
Предназначена для общих форматов данных, включая будущие `ToolCall` и `ToolResult`, а также для основного цикла агента. Сейчас содержит только заглушку.

## `src/providers/`
Предназначена для адаптеров к моделям и API. Здесь смогут размещаться реализации для Anthropic и других провайдеров в будущем; сейчас содержит только заглушку.

## `src/planner/`
Предназначена для построения и отслеживания многошаговых планов агента. Планировщик пока не реализован, директория подготовлена для будущей разработки.

## `src/memory/`
Предназначена для долгосрочной памяти агента. Механизм памяти пока не реализован, директория содержит только подготовительную заглушку.
