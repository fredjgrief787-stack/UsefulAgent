# Как запустить Anime Agent

## Быстрый старт

1. Убедись, что в `.env` есть `ANTHROPIC_API_KEY`
2. Выполни команды:

```bash
cd C:\dev\anime-agent
pnpm build
pnpm start
```

3. Попробуй запросы:
   - `Прочитай src/index.ts и объясни, как он работает`
   - `Покажи структуру проекта`
   - `exit` для выхода

## Что было сделано

### Созданные файлы:
- `src/tools/definitions.ts` - типизированные определения инструментов для Anthropic API
- `src/tools/executor.ts` - обработчик выполнения инструментов
- `src/prompt.ts` - системный промпт на русском языке
- `test-agent.js` - тестовый скрипт
- `README.md` - документация проекта

### Изменённые файлы:
- `src/index.ts` - добавлен полный цикл tool use с обработкой `tool_use` и `tool_result`
- `package.json` - добавлены скрипты сборки и запуска, установлен `"type": "module"`
- `tsconfig.json` - исправлена конфигурация для корректной компиляции в ES модули

### Что теперь умеет агент:

✅ **Tool Use Protocol** - полная поддержка инструментов через Anthropic API
✅ **Автоматический выбор инструментов** - Claude сам решает, когда использовать инструменты
✅ **Множественные вызовы** - может вызывать несколько инструментов за один запрос
✅ **Обработка результатов** - правильная обработка `tool_result` и возврат в цикл
✅ **Системный промпт** - понятные инструкции для Claude на русском
✅ **Обратная совместимость** - старые команды `/tree` и `/read` всё ещё работают
✅ **Обычное общение** - можно просто разговаривать с Claude без инструментов

### Архитектура:

```
Пользователь
    ↓
Основной цикл (index.ts)
    ↓
Claude API (с tools + system prompt)
    ↓
Tool use? → Да → Executor → Выполнение → Результат → Обратно Claude
    ↓ Нет
Текстовый ответ пользователю
```

### Инструменты:

1. **read_file** - чтение содержимого файлов
2. **get_directory_tree** - отображение структуры директорий

Оба инструмента полностью интегрированы с Claude API.
